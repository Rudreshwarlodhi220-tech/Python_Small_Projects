# Data Analysis Portfolio
This repository contains a collection of my data analysis projects, where I have used Python to extract insights from various datasets, ranging from stock market trends to sales performance.
## 📊 Projects Included:
### 1. Netflix Stock Price Analysis (2002 - 2022)
 * **Description:** An exploratory data analysis of Netflix's stock market performance over two decades.
 * **Key Objectives:**
   * Analyzing the volume of stock traded.
   * Visualizing stock trends (Open, High, Close prices).
   * Analyzing stock fluctuations based on day, month, and year.
   * Identifying the top 5 dates with the highest and lowest stock prices.
 * **Technologies:** Python, Pandas, Matplotlib, Seaborn.
### 2. IPL 2022 Match Analysis
 * **Description:** A detailed analysis of the 2022 IPL season, focusing on match outcomes and player performance data.
 * **Key Insights:** Evaluating team performances, win/loss patterns, and tournament statistics.
 * **Technologies:** Python, Data Visualization.
### 3. iPhone Sales Analysis
 * **Description:** A comparative analysis of iPhone sales data.
 * **Key Objectives:** * Comparing sales performance across different models.
   * Identifying the highest and lowest selling trends to understand market demand.
 * **Technologies:** Python, Pandas, Data Cleaning.
## 🛠️ How to run these projects:
 1. Clone this repository to your local machine.
 2. Ensure you have **Jupyter Notebook** or **VS Code** installed.
 3. Install the necessary libraries using:
   ```bash
   pip install pandas matplotlib seaborn
   
   ```
 4. Open the .ipynb files in the respective project folders to view the analysis and code.
